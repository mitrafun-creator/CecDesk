# Аппаратная часть, прошивка и фоновая работа

> **Устройство:** `CEC-EMU dev/r.1 by Dimitryi Garutt`  
> **Платформа:** ESP32-S3-WROOM-1 (N16R8)  
> **Целевой ТВ:** Philips 32PFL9705H/60 (Шасси Q551.1E LA, EasyLink)

---

## 1. Схема пайки и подключения

Эмулятор включается в разрыв HDMI кабеля между видеокартой ПК и телевизором через переходную плату HDMI (Breakout board).

Для полной работы шины CEC требуется припаять **всего два провода**:

| Контакт на плате HDMI | Сигнал шины | Куда паять на ESP32-S3 | Описание |
| :--- | :--- | :--- | :--- |
| **Контакт 13** | **CEC** (Consumer Electronics Control) | **GPIO4** | Линия шины данных 3.3 В (Open-Drain). Внутри телевизора уже подтянута к 3.3 В через резистор 27 кОм. |
| **Контакт 17** | **GND** (Ground) | **GND** | Общая сигнальная земля между HDMI и микроконтроллером. Без нее передача невозможна. |
| **Контакты 15, 16, 18** | SCL, SDA, +5V | **НЕ ПОДКЛЮЧАТЬ!** | 5-вольтовые линии DDC/I2C могут повредить ESP32-S3. |

### Нюанс видеокарт (NVIDIA / AMD):
Если на видеокарте 13-й контакт внутри порта подтянут к массе, линия CEC просядет в LOW. Для решения достаточно **перерезать дорожку 13-го пина на переходной плате** со стороны разъема, идущего в видеокарту, оставив соединение только между ESP32-S3 и телевизором.

## 2. Прошивка микроконтроллера

Прошивка собирается с помощью **PlatformIO Core**:

```powershell
cd c:\Users\Димитрий\Desktop\Tools\HDMI_CEC_Emulator\firmware
& "C:\Users\Димитрий\AppData\Local\Programs\Python\Python311\Scripts\pio.exe" run -t upload
```

### Режим аварийного загрузчика (ROM Bootloader)
Если плата временно не определяется на COM-порту (или менялся USB стек):
1. Зажмите кнопку **BOOT** (GPIO0) на плате ESP32-S3.
2. Не отпуская кнопку BOOT, вставьте USB-кабель в ПК (или кратковременно нажмите кнопку **RST / EN**).
3. Отпустите кнопку BOOT.
4. В диспетчере устройств появится аппаратный порт загрузчика **COM6**, после чего команда прошивки `pio run -t upload` запишет прошивку в flash-память.

## 3. Дескрипторы устройства в системе

Устройство идентифицируется в операционной системе и программном обеспечении как:
- **Название устройства:** `CEC-EMU dev/r.1 by Dimitryi Garutt`
- **Производитель:** `Dimitryi Garutt`
- **Серийный номер:** `CEC-EMU-001`
- **VID / PID:** `0x303A:0x1001`

Приложение `HDMI-CEC Studio` автоматически распознает плату по этим сигнатурам и моментально подключается без необходимости вручную выбирать COM-порт.

## 4. Фоновый режим и системный трей

Приложение **HDMI-CEC Studio** умеет работать полностью в фоновом режиме:

1. **Сворачивание в трей вместо закрытия:**
   - При нажатии на крестик («Закрыть») окно приложения не уничтожается, а мгновенно скрывается в системный трей Windows.
   - Все фоновые службы (перехват пульта, режим мыши, умная перемотка, экранная клавиатура, автопереключение звука) продолжают непрерывно работать.

2. **Значок в системном трее:**
   - **Одинарный левый клик** по значку в трее: разворачивает окно приложения на экран (или сворачивает, если оно открыто).
   - **Правый клик** по значку открывает меню быстрого доступа:
     - *Открыть HDMI-CEC Studio*
     - *Свернуть в трей*
     - *Режим мыши (Вкл / Выкл)*
     - *Выход из программы* (полное завершение процесса).
