# Аппаратная часть, распиновка и прошивка контроллера

> **Устройство:** `CEC-EMU dev/r.1 by Dimitryi Garutt`  
> **Поддерживаемые платы:** RP2040-Zero (PIO State Machine) и ESP32-S3 (Open-Drain GPIO4)  
> **Режимы USB:** USB CDC Serial (`115200 bps`), автоопределение по VID/PID (`0x2E8A` / `0x303A`)

---

## 1. Схема пайки и подключения HDMI-CEC

Эмулятор включается в разрыв HDMI-кабеля между видеокартой ПК / Steam Deck и телевизором через переходную плату HDMI (Breakout board).

Для базовой работы шины CEC требуется припаять **всего два провода**:

| Линия HDMI / Плата | Назначение | RP2040-Zero | ESP32-S3 | Примечание |
| :--- | :--- | :--- | :--- | :--- |
| **Контакт 13 HDMI** | **CEC** (линия данных 3.3 В) | **GP0** | **GPIO4** | Open-Drain шина 3.3 В. Подтянута к 3.3 В внутри телевизора (27 кОм). |
| **Контакт 17 HDMI** | **GND** (земля сигнала) | **GND** | **GND** | Общая сигнальная земля между HDMI и микроконтроллером. |
| **Контакты 15, 16, 18** | SCL, SDA, +5V | **НЕ ПОДКЛЮЧАТЬ!** | **НЕ ПОДКЛЮЧАТЬ!** | 5-вольтовые линии DDC/I2C могут повредить входы 3.3 В микроконтроллера. |

### Опциональное управление питанием ПК через оптопару (PC817)

Если вы хотите включать системный блок с пульта телевизора даже из полностью выключенного состояния (S5), подключите оптопару параллельно кнопке питания материнской платы:

| Функция | RP2040-Zero | ESP32-S3 | Описание |
| :--- | :--- | :--- | :--- |
| **Оптопара PWR_BTN** | **GP1** | **GPIO5** | Импульс 350 мс при включении ТВ / входе HDMI-ПК. |
| **Оптопара RESET_BTN** | **GP2** | **GPIO6** | Опциональный импульс сброса. |
| **Контроль PWR_LED+** | **GP3** | **GPIO7** | Вход определения состояния питания материнской платы. |

### Важный нюанс видеокарт (NVIDIA / AMD / Док-станции)
Некоторые видеокарты или HDMI-переходники удерживают 13-й контакт на массе (0 В) при выключенном ПК или конфликтуют на шине, из-за чего линия CEC проседает в `LOW` (в интерфейсе горит красный статус **«0V / Ошибка»**).  
Для решения достаточно **перерезать дорожку 13-го контакта на переходной плате HDMI** со стороны разъёма, идущего в видеокарту, оставив соединение пина 13 **только между контроллером и телевизором**. Линии TDMS видео/аудио и EDID (пины 15–19) остаются сквозными.

## 2. Прошивка микроконтроллера

### Способ А — Встроенный прошивальщик прямо в HDMI-CEC Studio (рекомендуется)
Готовые образы прошивки уже вложены в релизную папку `bin/firmware/`:
- `bin/firmware/rp2040_zero_firmware.uf2` (для RP2040-Zero)
- `bin/firmware/esp32_s3_firmware.bin` (для ESP32-S3)

Порядок действий:
1. Подключите плату к ПК по USB.
2. Откройте приложение **HDMI-CEC Studio -> Настройки -> Прошивка контроллера**.
3. Нажмите **«Прошить (v1.1.0)»** (или выберите свой `.uf2`/`.bin` через «Из файла»).
   - Для **RP2040-Zero**: приложение автоматически перезагрузит плату в режим загрузчика `RPI-RP2` (или используйте уже смонтированный диск после подключения с зажатой кнопкой **BOOT**) и скопирует `.uf2`.
   - Для **ESP32-S3**: обновление передаётся напрямую по USB Serial (встроенный Serial OTA без сторонних утилит).

### Способ Б — Ручная сборка и прошивка через PlatformIO (для разработчиков)

Выполните из корня репозитория (после установки PlatformIO Core / `pio`):

```powershell
# Сборка и прошивка RP2040-Zero (.pio\build\rp2040-zero\firmware.uf2)
cd firmware
pio run -e rp2040-zero

# Или сборка и загрузка на ESP32-S3 (укажите фактический COM-порт вашей платы)
pio run -e esp32-s3-devkitc-1 -t upload --upload-port COM<N>
```

На Windows также доступны вспомогательные скрипты в корне репозитория:
- `flash_rp2040.bat` (можно передать порт: `flash_rp2040.bat COM5`) — собирает `.uf2` для RP2040-Zero и копирует на диск `RPI-RP2`.
- `flash_firmware.bat` — вызывает PlatformIO для прошивки ESP32-S3.

### Режим аварийного загрузчика (ROM Bootloader)
Если плата временно не определяется на COM-порту:
- **RP2040-Zero:** зажмите кнопку **BOOT**, подключите USB-кабель к ПК и отпустите кнопку — появится съёмный диск `RPI-RP2`. Скопируйте на него `bin/firmware/rp2040_zero_firmware.uf2` (или воспользуйтесь кнопкой прошивки в UI).
- **ESP32-S3:** зажмите **BOOT** (GPIO0), не отпуская вставьте USB-кабель (или кратковременно нажмите **RST/EN**), затем отпустите **BOOT** — появится порт загрузчика для прошивки через PlatformIO.

## 3. Дескрипторы устройства в системе

Прошитый контроллер распознаётся в приложении автоматически по USB VID/PID и дескрипторам:
- **Название устройства:** `CEC-EMU dev/r.1 by Dimitryi Garutt` (или стандартные VID/PID контроллеров)
- **VID / PID:** `0x2E8A` (Raspberry Pi RP2040-Zero) и `0x303A:0x1001` (ESP32-S3 / кастомный CDC дескриптор)

Приложение `HDMI-CEC Studio` автоматически находит подходящий последовательный порт и поддерживает переподключение при обрыве кабеля через Watchdog.

## 4. Фоновый режим и системный трей

1. **Сворачивание в трей вместо закрытия:**
   - При нажатии на крестик («Свернуть в трей») окно скрывается в область уведомлений Windows, а перехват пульта, режим мыши, HUD, экранная клавиатура и автопереключение звука продолжают работать в фоне.
   - На SteamOS / Linux приложение может работать как фоновый сервис `systemd` (`hdmi-cec-studio.service`), сохраняя активность в Gaming Mode (Gamescope) и на рабочем столе.

2. **Значок в системном трее:**
   - **Одинарный левый клик** по значку: разворачивает или сворачивает главное окно.
   - **Правый клик** открывает быстрое меню:
     - *Открыть HDMI-CEC Studio*
     - *Свернуть в трей*
     - *Режим мыши (Вкл / Выкл)*
     - *Steam Big Picture (Открыть / Закрыть)*
     - *Выход из Big Picture на рабочий стол*
     - *Экранная клавиатура (Steam / OSK)*
     - *Выход из программы* (полное завершение процесса).
