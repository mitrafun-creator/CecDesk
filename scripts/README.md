# Руководство по пользовательским сценариям и скриптам CEC Studio

Папка `scripts` предназначена для размещения ваших собственных скриптов, командных файлов и программ.
Каждый добавленный файл **автоматически обнаруживается CEC Studio** и появляется в списке действий во вкладке **«Кнопки»** (Назначение кнопок пульта).

---

## 1. Принцип именования и отображения

* **Имя файла без расширения** = **Название сценария в CEC Studio**.
  * Например, файл `МЕМ (Rickroll).bat` будет отображаться в списке как `📜 Сценарий: МЕМ (Rickroll)`.
  * Файл `Запустить Кинопоиск.cmd` появится как `📜 Сценарий: Запустить Кинопоиск`.
  * Файл `Выключить монитор.ps1` появится как `📜 Сценарий: Выключить монитор`.

---

## 2. Поддерживаемые форматы файлов

| Расширение | Назначение | Как исполняется |
|------------|------------|-----------------|
| `.bat`     | Классический командный файл Windows | Запускается через `cmd.exe /c` в скрытом режиме (без всплывающего черного окна). |
| `.cmd`     | Командный сценарий Windows NT | Запускается через `cmd.exe /c` в скрытом фоновом режиме. |
| `.ps1`     | Сценарий PowerShell | Запускается через `powershell -ExecutionPolicy Bypass -File ...` в скрытом режиме. |
| `.vbs`     | Скрипт VBScript | Запускается через `wscript //nologo ...` в фоновом режиме. |
| `.exe`     | Исполняемый файл / утилита | Запускается напрямую в отдельном процессе. |
| `.lnk`, `.url` | Ярлык Windows или ссылка | Открывается системным обработчиком по умолчанию. |

## 3. Примеры сценариев

### Пример 1: Открытие сайта или видео (`.bat`)
```cmd
@echo off
chcp 65001 >nul
start "" "https://www.youtube.com"
exit /b 0
```

### Пример 2: Запуск приложения или игры (`.bat`)
```cmd
@echo off
start "" "C:\Program Files\VideoLAN\VLC\vlc.exe"
exit /b 0
```

### Пример 3: Переключение аудиоустройства или монитора (`.ps1`)
```powershell
# Скрипт переключения вывода на телевизор или запуск Steam
Start-Process "steam://open/bigpicture"
```

### Пример 4: Запуск скрипта с клавиатурными комбинациями (`.bat`)
```cmd
@echo off
chcp 65001 >nul
:: Открываем приложение и эмулируем горячие клавиши через WScript.Shell
start "" "https://music.youtube.com"
powershell -WindowStyle Hidden -Command "$ws = New-Object -ComObject wscript.shell; Start-Sleep -Seconds 2; $ws.SendKeys(' ');"
exit /b 0
```

## 4. Особенности и ограничения

1. **Фоновое выполнение**:
   * Все скрипты запускаются **асинхронно** в отдельном потоке. Это гарантирует, что даже долгий скрипт не заморозит отклик пульта и шину CEC.
   * По умолчанию запуск происходит **без мелькания консоли** (`CREATE_NO_WINDOW`). Если вам нужно отобразить окно командной строки, используйте внутри `.bat` команду `start cmd /k ...`.

2. **Рабочая папка (Working Directory)**:
   * Текущим рабочим каталогом скрипта при запуске является эта папка `scripts\`. Если вы используете относительные пути к соседним файлам, они будут разрешаться относительно этой папки.

3. **Права доступа и UAC**:
   * Скрипты выполняются от имени текущего пользователя Windows.
   * Если вашему скрипту требуются права Администратора (UAC), запуск с пульта может быть заблокирован модальным диалогом UAC. Рекомендуется использовать команды, не требующие повышенных привилегий, либо настраивать запуск через Планировщик заданий Windows (`Task Scheduler`).

4. **Кодировка для кириллицы**:
   * Для `.bat` файлов с русскими символами рекомендуется добавлять в самое начало:
     `chcp 65001 >nul`
   * Сохраняйте текстовые файлы в кодировке **UTF-8**.

5. **Бесконечные циклы**:
   * Избегайте бесконечных циклов (`:loop ... goto loop`) без пауз или условий выхода, чтобы не нагружать процессор.

---

## 5. Как применить сценарий на кнопку пульта

1. Поместите ваш файл скрипта в эту папку (`scripts\`).
2. В приложении **CEC Studio** перейдите во вкладку **«Кнопки»**.
3. В выпадающем списке нужной кнопки выберите ваш сценарий (он будет начинаться со значка `📜 Сценарий: ...`).
4. Нажмите кнопку **«Сохранить»**.
5. Теперь при нажатии выбранной кнопки на пульте телевизора ваш скрипт мгновенно выполнится!
