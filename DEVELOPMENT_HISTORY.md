# История разработки HDMI-CEC Studio

## Этап 1: Прототип и реверс-инжиниринг протокола HDMI-CEC
- Реализация аппаратного моста на ESP32-S3 (Open-Drain GPIO4 с внешним подтягивающим резистором к линии CEC 3.3V).
- Интеграция библиотеки CEC-master и реализация протокола обмена USB CDC Serial на скорости 115200 бод.
- Создание базовых профилей ТВ (Philips EasyLink, LG SimpLink, Samsung Anynet+, Sony Bravia Sync).

## Этап 2: Tauri v2 Backend & UI Архитектура
- Переход на Tauri v2 с модульной архитектурой на Rust:
  - `hardware/serial_transport.rs`: отдельный поток с кольцевым буфером для работы с COM-портом.
  - `hardware/remote_dispatcher.rs`: маршрутизация CEC-фреймов, диспетчеризация команд пульта.
  - `hardware/mouse_engine.rs`: управление курсором мыши со стрелок пульта с адаптивным ускорением.
  - `hardware/watchdog.rs`: мониторинг линии и автоматическое переподключение USB.
- Разработка интерфейса на Vanilla JS (без тяжелых фреймворков для мгновенного отклика и минимального потребления памяти):
  - Темная тема в стиле Apple HIG с эффектом стеклянного морфизма (Glassmorphism).
  - Динамический конструктор пульта `remote_builder.js`.
  - Интерактивный режим обучения (калибровки) `calibration.js`.
  - Таблица назначения клавиш `key_mapper.js`.

## Этап 3: Повышение надежности, безопасность и устранение P0 дефектов
1. **Динамические пути в конфигурации и логах**:
   - Устранены абсолютные жестко закодированные пути к папкам сборки.
   - Реализован автоматический поиск рабочей директории относительно пути исполняемого файла (`std::env::current_exe()`).
   - Логи и паники безопасно записываются в папку `logs/` через `find_logs_dir()`.
2. **Безопасная миграция конфигурации**:
   - Автоматическая миграция устаревших значений `"MEME"` в `"NUM_0"` или `"NONE"` при загрузке `cec_studio_config.json`.
   - Создан базовый шаблон `cec_studio_config.default.json`, локальные данные пользователя защищены через `.gitignore`.
3. **Надежный Single-Instance механизм**:
   - Реализована проверка единого экземпляра приложения через глобальный именованный мьютекс Windows (`CreateMutexW`).
   - Дескриптор мьютекса сохраняется в статической памяти для предотвращения преждевременного освобождения.
   - При повторном запуске приложение мгновенно находит существующее окно по заголовку и переводит на него системный фокус (`ShowWindow`, `SetForegroundWindow`).
4. **Унификация буквенных обозначений неизвестных кнопок**:
   - В модуле `catalog.js` создана единая функция `getExtraKeyLetterMap(activeKeys)` с двухбуквенной индексацией (`A`..`Z`, `AA`..`AZ`), гарантирующая точное соответствие кнопок на виртуальном пульте и в таблице маппера.
   - Добавлена функция `profileShortName(prof)` для единообразного отображения названий моделей ТВ без служебных скобок.

## Этап 4: Модернизация интерфейса (Apple HIG Design System)
1. **Токены дизайн-системы в `style.css`**:
   - Шкала типографики: `--fs-caption` (11px), `--fs-footnote` (12px), `--fs-body` (13px), `--fs-headline` (15px), `--fs-title` (20px), `--fs-largetitle` (28px).
   - Шкала отступов кратная 4: от `--sp-1` (4px) до `--sp-6` (24px).
   - Шкала радиусов: `--r-sm` (8px), `--r-md` (12px), `--r-lg` (18px), `--r-xl` (28px).
   - Стандартизированные тени `--shadow-1`, `--shadow-2`, `--shadow-3` и длительности переходов `--dur-fast`, `--dur`, `--dur-slow`.
2. **Доступность и адаптивность**:
   - Реализован стиль клавиатурного фокуса `:focus-visible` на всех интерактивных элементах (кнопках, полях ввода, свитчах).
   - Добавлена поддержка `@media (prefers-reduced-motion: reduce)` для мгновенного отключения ресурсоемких анимаций.
   - Добавлен адаптивный медиа-запрос `@media (max-width: 960px)` с переключением на вертикальный стек с плавной прокруткой.
3. **Интерактивные элементы**:
   - Глобальные горячие клавиши: `Ctrl+1`, `Ctrl+2`, `Ctrl+3` для быстрого переключения экранов, `Ctrl+S` для сохранения маппинга, `Escape` для безопасного выхода из режима калибровки.
   - Стилизованные группы `inset-group` и строки `inset-row`.
   - Рефакторинг и очистка inline-стилей в `index.html`.

## Этап 5: Защита данных, оптимизация шины и автоматическое тестирование
1. **Двухуровневая защита пользовательских названий профилей**:
   - Добавлено поле `display_name` в `TvProfile` и словарь `custom_profile_names` в `AppConfig`. Пользовательские имена сохраняются и восстанавливаются независимо от обновления локальных файлов онлайн-синхронизацией.
2. **Дедупликация heartbeat-логов линии CEC**:
   - В потоке `serial_transport.rs` внедрен фильтр повторяющихся сообщений `OK:LINE_...`. Лог не забивается идентичными строками каждые 8 секунд, а фиксирует только реальные переключения и изменения состояния линии.
3. **Управление отладкой и диагностикой**:
   - Логирование шагов запуска `log_step` скрыто за флагом `--debug` / `CEC_DEBUG`. Аварийные паники продолжают логироваться безусловно.
4. **Динамическая идентификация адаптеров**:
   - В прошивку добавлена команда `INFO`/`VERSION` с автоопределением чипа (ESP32-S3 / RP2040-Zero). Интерфейс динамически определяет модель подключенного адаптера по ответу прошивки и свойствам COM-порта, выводя корректную модель в заголовок окна.
5. **Безопасность запуска скриптов и тесты**:
   - В `custom_scripts.rs` добавлена защита от Path Traversal (блокировка путей с `..`, слешами и проверка выхода за канонический каталог `scripts/`).
   - Добавлены Rust unit-тесты (`cargo test`) для защиты скриптов и миграций конфигурации (2 из 2 успешно).
   - Добавлены Node.js unit-тесты (`node --test`) для функций `catalog.js` (3 из 3 успешно).
